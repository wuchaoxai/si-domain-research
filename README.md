# .si 域名研究总表

中文双拼、AI中英文热词、欧美人名、通用品牌词、已有公司与产品名，以及其他后缀成交词的 `.si` 查询记录。由吴超与多个AI协作任务整理，免费分享，方便复用结果、查漏补缺。

**这是一份2026年9月30日至10月1日的研究快照，不是实时可注册清单。** 请先看每个域名的状态和查询时间，再到注册商核验。作者已停止继续囤积，分享不代表鼓励把整份榜单注册下来。

## 怎么看排序

只看 **研究推荐分（0—100）**：数字越大越优先，同分沿用原复评顺序。候选榜的“顺位”只是行号，1代表第一行，**不是另一套评分**。本版保留既有冻结分，仅更新持仓及查询结果，没有伪造新买家意向或全池重新估值。

无分代表未做同口径评估、已持有或自用条目，不等于零分。分数只帮助安排调查顺序，不能解释成卖出概率、预期售价或交易保证。技术词或已有品牌得到一定分数，也不代表适合每个投资者囤积；购买前仍应核对独立用途、具体买家及名称权利。

## 状态含义

| 状态 | 可以据此知道什么 |
|---|---|
| 近期有普通注册报价 | 标注时间注册商出现BUY；付款前仍需确认 |
| 仅历史可注册证据 | 只有较早证据；应重新查询 |
| 转入入口 | TRANSFER，不是普通新注册报价，不列入候选榜 |
| 注册局有注册记录 | 保存的注册局查询返回200；不列入候选榜 |
| 注册商/注册局冲突 | TRANSFER与RDAP404不一致；暂停推荐，不能认定已被抢注 |
| 作者已持有 | 46项最新账户导出显示ACT；均移出候选榜 |
| 历史有记录或不可普通注册 | 原池当时未得到普通注册结果；需要时再复核 |

RDAP404本身不能保证能买。报价仅代表对应注册商和时间，不是作者支付价格；转入价格不作为新注册价格公开。最新信号和历史证据分别保存，避免用今天的状态抹去昨天的观察。

## 品牌和成交记录

已有品牌的同名采用，可能提供潜在业务线索，但尚无采购意向的不能称为客户。公开表未完成逐名商标净空或法律审查；列出名称及分数不构成注册安全承诺，也不表示该品牌认可本项目。

成交映射来自公开报道，保留原域名、原币种、日期及来源链接。`.com`、`.ai`等后缀的成交价不能直接变成同词 `.si` 的估值。44条映射也不是本研究产生的成交成果。

## 更新和复用

若提交状态更正，请提供域名、查询时间（注明时区）、注册商或注册局公开链接，以及BUY、TRANSFER或注册局结果。不要提交密码、转移授权码、账户导出、cookie或付款资料。

公开包仅包含字段白名单投影；本机路径、内部对话标识、账户身份、授权码、自动续费、实际支付及到期信息均未上传。原始私人工作区和聊天记录不在此仓库内。

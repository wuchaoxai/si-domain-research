# .si 域名研究总表

中文双拼、AI中英文热词、欧美人名、通用品牌词、已有公司与产品名，以及其他后缀成交词的 `.si` 查询记录。由吴超与多个AI协作任务整理，免费分享，方便复用结果、查漏补缺。

**这是一份2026年9月30日至10月5日的研究快照，不是实时可注册清单。** 请先看每个域名的状态和查询时间，再到注册商核验。本版作者持有120个域名。分享供研究与查漏补缺，不代表鼓励把整份榜单注册下来。

## 研究投入与复核方式

本研究由吴超发起，多条AI协作任务并行查询、合并及复核。按发起人提供的配置说明，研究主要使用 **GPT 6.1 SOL，High推理档**；工作累计约30小时，发起人估计累计投入20亿—30亿token（至少20亿）。**token量未按本项目独立计量或审计，这一估算与模型配置不构成数据准确率证明，也不表示每个子任务都由同一模型执行。**

如果要重新评估候选价值和推荐顺序，建议使用同级或更强模型、足够推理预算，并完整读取评分口径与来源。请避免仅凭另一个模型的无来源结论推翻记录；更正应提供具体域名、原记录、查询时间和可复核证据。注册商或注册局的新证据、明确的数据错误均可用于修正，不以模型等级作为受理门槛。名称推荐仍含主观判断，可注册状态也会随时间变化。

## 怎么看排序

只看 **研究推荐分（0—100）**：数字越大越优先，同分沿用原复评顺序。候选榜的“顺位”只是行号，1代表第一行，**不是另一套评分**。本版保留既有冻结分；新增词的命名适配分、查询优先级和人物资料质量没有混入投资评分。未做同口径投资评估的新增可查候选放在有分条目之后，评分栏留空；没有伪造新买家意向或全池重新估值。

无分代表未做同口径评估、已持有或自用条目，不等于零分。分数只帮助安排调查顺序，不能解释成卖出概率、预期售价或交易保证。技术词或已有品牌得到一定分数，也不代表适合每个投资者囤积；购买前仍应核对独立用途、具体买家及名称权利。

## 状态含义

| 状态 | 可以据此知道什么 |
|---|---|
| 近期有普通注册入口 | 标注时间注册商出现BUY或Add to Cart；付款前仍需确认 |
| 仅历史可注册证据 | 只有较早证据；应重新查询 |
| 转入入口 | TRANSFER，不是普通新注册报价，不列入候选榜 |
| 注册局有注册记录 | 保存的注册局查询返回200；不列入候选榜 |
| 注册商/注册局冲突 | 多注册商结果或注册商与注册局不一致；暂停推荐，不能认定已被抢注 |
| 作者已持有 | 120项最新账户导出显示ACT；均移出候选榜 |
| 历史有记录或不可普通注册 | 原池当时未得到普通注册结果；需要时再复核 |

RDAP404本身不能保证能买。报价仅代表对应注册商和时间，不是作者支付价格；转入价格不作为新注册价格公开。最新信号和历史证据分别保存；JSON和域名CSV增加逐名 `query_history` 观察记录，Excel增加“增量查询观察”列。每项保留原UTC时间和公开来源，避免用今天的状态抹去昨天的观察。状态变化不能直接证明谁在何时注册。

## 品牌和成交记录

已有品牌的同名采用，可能提供潜在业务线索，但尚无采购意向的不能称为客户。公开表未完成逐名商标净空或法律审查；列出名称及分数不构成注册安全承诺，也不表示该品牌认可本项目。

成交映射来自公开报道，保留原域名、原币种、日期及来源链接。`.com`、`.ai`等后缀的成交价不能直接变成同词 `.si` 的估值。44条映射也不是本研究产生的成交成果。

## 更新和复用

若提交状态更正，请提供域名、查询时间（注明时区）、注册商或注册局公开链接，以及BUY、TRANSFER或注册局结果。不要提交密码、转移授权码、账户导出、cookie或付款资料。

公开包仅包含字段白名单投影；本机路径、内部对话标识、账户身份、授权码、自动续费、实际支付及到期信息均未上传。原始私人工作区和聊天记录不在此仓库内。
